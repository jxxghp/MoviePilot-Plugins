# LunaTV 资源订阅（MoviePilot V3）

接入 MoonTV/LunaTV 的 Apple CMS 资源站，复用 MoviePilot 原生搜索、订阅、目录、TMDB、整理和媒体库链路。插件只负责源适配与下载队列。

## 使用要点

- 订阅地址内的资源站默认全部读取；目录复用 MoviePilot 的本地目录设置，不再重复配置白名单或下载路径。
- 插件工作台按配置间隔（默认 60 分钟）后台检查资源站健康与搜索能力，只让健康且已启用的来源参与搜索；支持永久停用、重新启用和立即复检。
- 下载队列默认同时运行 2 个任务，每个任务使用 16 个分片线程；任务数可配置为 1–4，分片线程可配置为 4–32，二者乘积限制在 64 以内。同一目标文件始终串行，避免争用同一个 `.part` 或成品文件。
- 片名自动读取 MoviePilot 智能助手（DeepSeek 等 OpenAI 兼容模型），未配置或失败时自动回退规则清理。
- LunaTV 结果参与 MoviePilot 顶部全局搜索，并使用原生详情、资源搜索、订阅和下载入口；插件不再提供重复搜索页或独立订阅导航。
- 搜索结果自动关联 TMDB；多季合集会按作品季集数安全映射。
- 电视剧资源按“来源 + 季”聚合为原生资源卡片，点击后按整季排队；不同集可按队列并发设置执行，原生下载管理可显示进度并支持暂停、继续和删除。
- M3U8 VOD 下载仅使用 [N_m3u8DL-RE](https://github.com/nilaoda/N_m3u8DL-RE)；FFmpeg 仅作为其混流依赖，不是回退下载器。暂停、失败和重启恢复会保留任务专用缓存以便续传。
- 第三方组件、用途和许可证索引见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
- 订阅刷新会检查 MoviePilot 原生 TMDB 下载历史；整理移动源文件或旧队列记录被裁剪后，也不会重复下载已完成的电影或电视剧季集。
- 目录、智能助手、TMDB、整理规则、媒体服务器和链接权限无需在插件中重复配置；媒体库同步沿用 MoviePilot 已启用的服务器设置。
- NFO 元数据默认关闭；开启后由 MoviePilot 原生整理链生成，插件不自写 XML。
- 插件不会绕过 DRM、登录保护或付费限制，请只使用你有权访问的资源源。

默认配置地址：

```text
https://raw.githubusercontent.com/hafrey1/LunaTV-config/main/LunaTV-config.json
```

请只启用有权访问的站点，并确保 MoviePilot 目录已正确映射到容器。
