# ChatGPT 识别增强

使用系统智能助手或 Agent Tokens 管理插件提供的模型配置辅助识别影视与音乐名称。

发送前会移除已知的 `[LoliHouse]` 制作组标签及方括号中的站点演职员后缀；片名、别名、年份、季集数、音视频和字幕信息保留，不修改原文件名及缓存键。

模型返回空候选或空文本时，提示可能为安全审查拒答或上游响应异常；只有响应明确包含拒答或安全拦截标记时才提示模型拒答。这些失败会保留日志和调用用量，不写入识别结果缓存，后续仍可重试。

开启错误通知后，同类空响应或拒答五分钟内只发送一次通知，影视与音乐识别共用此限制。其他错误按原配置发送通知。保存插件配置会重置通知计时。
