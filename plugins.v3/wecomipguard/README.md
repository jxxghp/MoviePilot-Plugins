# 企业微信可信IP助手（WeComIPGuard）

自动把动态公网 IP 同步到企业微信（WeCom / 企微）应用的**可信IP白名单**，解决企业微信应用调用时出现的 `not allow to access from your ip` 报错。

家宽 / 移动网络的公网 IP 会不定期变动，每次变动都要手动去企业微信后台改一遍可信IP，很麻烦。本插件定时检测 IP，一旦变化就自动写入所有配置过的应用。

## 功能

- **IPv4 严格校验**：只用 IPv4 专用接口，并用 `ipaddress` 校验地址本身，过滤私网 / 回环 / 保留地址，不会把 IPv6 或版本号误当 IP。
- **低 CPU 保活**：先发一次普通 HTTP 请求判断登录态，并把响应里的 `Set-Cookie` 合并回本地实现续期。只有探活失败才启动浏览器内核复核，常态下几乎不占 CPU。
- **不漏同步**：登录态失效时不会静默跳过，而是记下待同步标记；登录态恢复后自动补写。
- **写入后回读校验**：每个应用写完后重新打开配置弹窗读回，确认真的写进去了。
- **状态仪表盘**：插件详情页直接展示当前 IP、登录态、同步结果、待同步状态与明细。
- **多种 Cookie 来源**：CookieCloud、手动 HeaderString、内置扫码登录（支持手机验证码）。

## 配置

| 配置项 | 说明 |
|--------|------|
| 启用插件 | 总开关 |
| 立即检测一次 | 保存后立刻跑一次检测 |
| 发送通知 | 是否推送企业微信通知 |
| 调试日志 | 输出更详细的排查信息 |
| 覆盖已有IP | 开：直接覆写；关：按分号追加 |
| 从 CookieCloud 获取 Cookie | 从 CookieCloud 拉取企业微信 Cookie |
| 应用地址 | **必填**，多个用英文逗号分隔 |
| Cookie 失效后自动登录 | 失效后自动进入扫码登录流程 |
| IP 检测周期 | 默认 `*/11 * * * *` |
| Cookie 保活周期 | 默认 `*/5 * * * *` |
| 失效通知周期 | 关闭自动登录时生效，默认 `0 * * * *` |
| HTTP / 浏览器超时 | 默认 15 / 180 秒 |
| 手动 Cookie | 非必填，HeaderString 格式 |
| 接收二维码成员ID | 非必填，留空发给全部成员 |
| 自定义 IP 源 | 非必填，留空用内置源 |

内置 IP 源：
- `https://ddns.oray.com/checkip`
- `https://ipv4.icanhazip.com`
- `https://v4.ipip.net`
- `https://ipinfo.io/ip`

## 使用提示

1. **首次使用**：填好应用地址并启用，在详情页点「立即检测一次」，或直接等定时任务。
2. **登录态失效**：向 MoviePilot 应用回复 `#登录企业微信` 重新扫码。
3. **需要手机验证**：按 `#123456` 格式回复验证码。

### 如何获取应用地址

企业微信管理后台 → 应用管理 → 点开任一自建应用 → 页面地址栏形如：

```
https://work.weixin.qq.com/wework_admin/frame#/apps/modApiApp/0000000000000000
```

有多个应用就用英文逗号分隔填进「应用地址」。

## 依赖

无额外 Python 依赖。浏览器内核 `cloakbrowser` 由 MoviePilot V3 运行时镜像自带。
