# 种子黑名单

适用于 MoviePilot **3.2.3 及以上版本**。默认停用；在配置页勾选启用并保存，再从插件详情页管理规则。规则在资源选择阶段过滤候选，并在实际下载前再次检查，手动下载也适用。搜索列表仍可能显示被屏蔽的资源。

## 规则范围

- **关键词**：匹配种子标题或描述中的文字，去除规则首尾空白、Unicode NFC 规范化并忽略大小写；不是正则或通配符。可以限定一个现有站点 ID，留空则覆盖所有站点。
- **站点**：按 MoviePilot 的站点 ID 屏蔽该站所有种子；删除并重新添加站点后，新 ID 需重新设置规则。
- **下载历史**：在详情页“下载历史”中点击“屏蔽同站同名种子”。服务器按历史 ID 读取站点名称和完整种子标题，去除首尾空白并做 NFC 规范化后精确匹配，区分大小写。站点或种子改名后不再命中。缺少必要事实的历史不可添加。

没有可靠发布者身份时不推测发布者，也不按种子链接或 infohash 猜测同一资源。历史搜索沿用宿主公开查询，搜索**媒体标题或下载路径**；页面和接口不返回下载路径。

## 管理与保存

管理接口仅允许当前启用的管理员账号。规则最多 **1000 条**，重复添加不占用容量；达到上限请先删除规则。规则会一直保留，直到主动删除；停用插件不删除规则，删除下载历史也不会删除已创建的规则。每个插件分身使用独立数据。

插件配置只保存启用状态。规则通过宿主 PluginData 保存为一个带版本和修订号的文档，不保存 Cookie、Passkey、下载链接或其他认证数据。同一进程、同一插件实例的并发操作使用同一把锁，读取最新数据后保存，成功后才发布不可变快照；不承诺跨进程或多个同 ID 实例间的分布式并发写入。

读取失败或数据损坏时，管理页面显示错误并保留原始数据。**启用状态下无法读取规则会取消下载**，避免损坏数据变成空黑名单。可修复插件数据后刷新/重载，或停用插件恢复下载；保存失败时保留原规则并显示错误。

## 开发和验证

Python 使用宿主公开插件 SDK、事件、安全和数据访问入口，无额外 Python 依赖。测试放在仓库根 `tests/v3/torrentblacklist/`，不随插件下发：

```sh
MOVIEPILOT_BACKEND_PATH=/path/to/MoviePilot /path/to/MoviePilot/.venv/bin/python -m pytest tests/v3/torrentblacklist -q
```

前端在本目录使用 Node.js 24 与独立、精确版本的 npm 锁文件：

```sh
npm ci
npm test
npm run typecheck
npm run build
```

Vue 测试使用真实 Vuetify 组件，覆盖配置保存、规则增删、站点选择、分页、历史屏蔽、失败保留输入与过期响应；Python 测试不能替代组件测试。Config 将本地草稿通过 `save` 事件交给宿主保存。Page 使用宿主提供的 `api` 属性、完整响应包和运行实例 `pluginId`，不自行读取令牌或写死分身标识。

联邦构建暴露 `./Config` 和 `./Page`，共享宿主 Vue/Vuetify；插件样式均限定作用域并过滤 Vuetify 基础 CSS。发布前必须构建并提交完整 `dist/assets/`（包括所有引用的 JS/CSS 块），发布工作流不会代为构建。
