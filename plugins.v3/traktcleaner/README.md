# Trakt 观看清理

需要 MoviePilot 3.0.10 或更新版本。在配置中填写 Trakt Client ID 和 Client Secret，打开授权链接获取 PIN，保存后由插件换取并刷新令牌。

开启「试运行模式」可先查看匹配结果。插件只接受唯一精确同名且年份、媒体类型相符的观看记录；剧集还需核对该任务内所有视频的季集号，无法确认或存在未观看单集时跳过。

「延迟清理天数」为 0 时立即处理，正数时从首次确认满足条件起计时。队列按下载器和种子哈希分别保存；旧队列能确认唯一下载器时保留计时，来源有歧义时重新扫描计时。下载器删除失败会保留待清理条目供后续重试。

详情页的「立即清理」会实际删除该队列条目的任务，并按「同时删除文件」决定是否删除文件，即使处于试运行模式也会执行。手动操作需要以 MoviePilot 超级管理员登录，使用 POST JSON；普通用户无权调用清理或队列管理接口，页面不包含宿主 API 密钥。「清除发现」仅移除队列记录，下次扫描符合条件时重新计时。
