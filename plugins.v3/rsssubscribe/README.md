# 自定义订阅

定时读取自定义 RSS，识别媒体后添加订阅，或按条目直接下载。

## 下载查重

从 v3.1.1 起，带明确集号的单季资源在下载前会合并以下范围：

- 媒体库中已存在的剧集。
- 当前下载器中尚未整理的任务对应的已提交剧集，包括下载中、暂停和完成待整理的任务。
- 本轮 RSS 刷新中已成功提交的剧集，多个 RSS 地址共用这一范围。

同一媒体、同一季集的不同字幕或文件格式版本只提交一次。仍按 RSS 条目顺序处理，
启用「使用订阅优先级规则」时，先执行原有规则过滤；查重不会重新排序候选。
下载提交失败不会占用集数，后续版本仍可继续尝试。

合集只有部分剧集缺失时，只把缺集交给宿主下载链选取对应文件；磁力链等无法选集的资源
沿用宿主下载链的处理结果，不会退回整包重复下载。

下载历史必须同时匹配媒体来源、媒体 ID、季号、剧集组及当前下载器任务。
已从下载器删除或已标记「已整理」的任务不会因旧下载历史而阻止补集。
无明确集号或跨多季资源沿用原有直接下载行为，订阅动作沿用原有订阅链路。
