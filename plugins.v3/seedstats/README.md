# 站点保种统计（SeedStats）

MoviePilot V3 插件：按 tracker 汇总各站点在本机下载器中的做种情况，并合并 MoviePilot「站点数据」里的账户信息。

## 功能

- **按站点统计做种**：读取已配置下载器中的全部任务，按任务的 tracker 归属到站点，统计每个站点的
  `任务数 / 做种 / 暂停 / 其他`，以及 **辅种（做种中）**、**辅种暂停**、**辅种合计**。
- **做种体积**：统计做种任务的总体积与辅种体积，用于观察保种的实际容量。
- **合并账户信息**：从 MoviePilot 的「站点数据」读取 `上传 / 下载 / 分享率 / 等级 / 魔力 / 数据时间`。
- **时魔估算**：插件自己按刷新周期记录魔力快照，用 0.5~12 小时窗口估算 `时魔*`；
  首次运行没有足够快照时回退到站点数据的日级快照，并标记「粗估」。魔力减少等情况标记「异常」，
  不提供魔力的站点标记「无魔力」。**不是站点官方时魔，仅供参考。**
- **效率指标**：`效率*` = 每小时魔力 ÷ 做种体积(TB)，用于比较各站点保种换魔力的性价比。
- **趋势图**：按小时聚合保存最近 14 天快照，详情页展示最近 7 天的做种/辅种折线。
- **健康告警**：站点数据过期、零做种、tracker 未归属、已删除站点残留数据都会在页面顶部提示。
- **只读安全**：不会修改、暂停或删除任何任务；插件不申请任何额外 API。

## 统计口径

| 指标 | 口径 |
| --- | --- |
| 做种 | 下载器状态为 `seeding` / `seed_pending` 的任务 |
| 辅种（做种中） | 带「辅种」标签且**正在做种**的任务 |
| 辅种暂停 | 带「辅种」标签但处于 `stopped` / `paused` 的任务 |
| 辅种合计 | 前两者之和（做种数不包含暂停任务，因此辅种不会再大于做种） |
| 做种体积 | 做种任务的种子体积之和 |
| 站点数 / 合计 | 默认只统计当前 MoviePilot 配置的站点；已删除站点的残留数据单独提示、不计入合计 |

## 配置项

| 配置 | 说明 |
| --- | --- |
| 启用插件 | 总开关 |
| 显示首页仪表板 | 是否在首页仪表板中提供卡片 |
| 刷新间隔(分钟) | 后台统计周期，默认 60，最小 5 |
| 统计的下载器 | 多选，留空表示统计所有已启用下载器 |
| 站点数据过期阈值(小时) | 超过该时长未更新的站点标记「数据过期」，默认 24 |
| 合计包含已删除站点 | 关闭时只统计当前配置的站点 |
| tracker 站点映射 | 每行一条 `域名=站点名`，用于修正未识别的 tracker（如 `bgp.technology=BGP`） |

保存配置后会立即重新统计一次。

## 远程命令

- `/保种统计`：推送当前缓存的统计汇总（站点数、任务数、做种、辅种、体积、上传、Top5、告警）。

## 工作原理

- 统计在**后台线程定时执行并缓存**，页面与仪表板只读取缓存，因此打开即秒出，
  不会因为统计耗时拖慢 MoviePilot 的 Web 界面。
  > 提示：MoviePilot 只有一个 API worker，插件页面/仪表板接口中直接做重活会导致整个 Web 界面卡死。
- 读取下载器任务时优先使用 Transmission 原生接口的轻量字段（更快），失败时自动回退到通用接口；
  qBittorrent 等下载器走通用接口（速度略慢，功能一致）。
- 站点归属顺序：手动映射 → MoviePilot 站点索引器 → 已配置站点域名（含注册域名/前缀）兜底 →
  仍未命中则按 tracker 域名单独成行，并在页面提示可以手动映射。

## 安装

在 MoviePilot 的「设置 → 插件市场地址」中加入本仓库地址：

```
https://github.com/miguelito39721/MoviePilot-Plugins
```

随后在「插件」页面刷新市场，搜索「站点保种统计」即可安装。
