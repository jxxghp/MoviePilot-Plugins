# 特典播放顺序

MoviePilot V3 插件，要求 MP ≥ 3.2.6。通过 TMDb 的单集 external IDs 精确关联 TVDB，
将 Season 0 特典的播放位置写入 NFO，供 Jellyfin 等支持这些标签的媒体服务器读取。

## 安装

在 MoviePilot 插件市场中搜索并安装「特典播放顺序」。沿用 MP 的 TMDb API、TVDB V4 API Key、
TVDB PIN 和代理配置，无需在插件里重新填写密钥。插件不声明额外 Python 依赖。

## 使用和配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 启用插件 | 关闭 | 开启后，对新刮削的 TMDb 默认编号 Season 0 单集自动同步播放位置 |
| 扫描目录（每行一个） | 空 | MP 内可访问的本地目录；扫描范围内须包含剧集的 tvshow.nfo；留空不扫描 |
| 手动映射修正 | 空 | 每行以 TMDb 单集 ID 开头，后接 `,ignore`、`,tvdb=单集ID` 或逗号分隔的播放位置字段。支持 `#` 注释 |
| 仅预览（不修改 NFO） | 开启 | 存量扫描只显示预计改动 |
| 立即运行一次 | 关闭 | 保存配置后执行一次存量扫描；任务提交前自动复位，不会定时扫描 |
| 清空缓存 | 关闭 | 保存时执行一次并复位。若同时勾选「立即运行一次」，会先清空再扫描 |

修复已有文件：先启用插件、填写**整部剧目录或更高一级目录**，保持「仅预览」开启，
勾选「立即运行一次」并保存。到插件详情页核对逐集映射、结果及三个播放位置字段的前后值。
确认后关闭「仅预览」，再次勾选「立即运行一次」并保存。完成后建议重新开启「仅预览」。
「播放位置」中未变化的值只显示一次。变更的旧值带红底，新值带绿底，配色跟随亮暗主题。摘要显示扫描结束时间，文件名上方用小字显示带末尾分隔符的目录。表格展示全部扫描明细，可滚动查看。在「映射」列点选 TMDb 或 TVDB 单集 ID 即可选中数字，方便复制到手动修正规则中。
缺少映射或 TVDB 单集无法核实的条目显示为「待修正」，并在摘要中单独计数。

详情页只显示当前插件实例最近一次扫描的结果，重载后可重新运行预览。正式修复直接更新 NFO，
插件不生成备份或持久化报告。启用 MP 的 DEBUG 日志可查看每次补全的文件或单集、映射来源和字段变化。

完整的 TMDb 映射和有效的 TVDB 播放位置保存在 MP 的插件存储中，重启后可复用，无自动过期时间。
空结果或不完整的查询结果只在进程内保留 5 分钟，网络和服务错误会在后续查询重试。
TVDB 单集返回 404 时，插件跳过该响应的缓存，并移除对应的 TMDb 自动映射缓存。下次运行会重新查询该映射。
怀疑上游数据有变化时，勾选「清空缓存」并保存，下次扫描会重新查询。
后续扫描还会跳过已确认不是 Season 0 单集且状态未变化的 NFO，这部分识别缓存保留在进程内。

## 映射和安全行为

- 映射成功后，按本次结果更新 `airsafter_season`、`airsbefore_season`、`airsbefore_episode`。无值的字段会清除，对应的 Jellyfin 别名也一并处理。
- 使用 `,ignore` 保留该集原有 NFO，直接跳过查询和写入。
- 通过单集身份精确匹配，不要求 TMDb 与 TVDB 的特典集号相同；不按标题自动猜测。
- 查询 TVDB 时会核实 TMDb 默认季集身份与 TVDB 单集的剧集归属。手动修正填写的是**单集 ID**，格式错误或规则冲突会暂停插件处理。
- 当 API 查询缺密钥、无映射、返回 404 或失败时，插件报告原因并沿用基础 NFO。
- 存量修复使用 API 时会核对默认编号。直接指定位置时以 NFO 内一致的 TMDb 单集 ID 和 Season 0 编号为准。
- 不修改视频、字幕、剧集标题或季集编号；不扫描符号链接；文件被其他程序更新时跳过写入。
- 自动补全通过宿主 NFO 扩展点运行。与其他接管 NFO 生成的插件同时使用时，结果受宿主插件
  优先级影响，不保证多插件串联；可使用本插件的存量预览核实最终文件。
- 自动刮削结果由 MP 按原流程保存，可用于其支持的存储；存量修复仅支持本地目录。

## 手动修正示例

每行配置一集，每集选择一条规则。`#` 后面的文字作为注释。位置字段接受非负整数。

```text
# 查询指定 TVDB 单集的播放位置
938553,tvdb=8636540
# 直接指定位置，清除其他已有位置，跳过 TMDb 和 TVDB 查询
938554,airsafter_season=1
# 以 TVDB 结果为基础，指定的字段优先。空值将对应位置清除
938555,tvdb=8636542,airsbefore_season=2,airsbefore_episode=
# 保留这集的原有播放位置
1174618,ignore
```

三种位置字段可按需组合。设置 `tvdb=` 时，手动值优先，未在规则中填写的字段使用 TVDB 返回值。填写空值会清除对应的位置。`ignore` 应单独使用。

《我的妹妹哪有这么可爱》（TMDb 剧集 56353）的部分 TMDb 外部映射指向已失效的 TVDB 单集。
以下三条已通过剧集身份、日文标题及播出日期核对，核对日期为 2026-11-18：

```text
938553,tvdb=8636540
938554,tvdb=8636541
938555,tvdb=8636542
```

其 E01–E04 应在第 1 季后播放，E21–E23 应在第 2 季后播放。以上示例不会自动写入默认配置，
其他作品请按其实际单集身份填写。

## Jellyfin 验证

NFO 更新后需让 Jellyfin 重新读取该作品的本地元数据。本插件不自动刷新全库，也不修改
Jellyfin 设置。定向刷新后可检查单集的 `AirsAfterSeasonNumber`、`AirsBeforeSeasonNumber`、
`AirsBeforeEpisodeNumber`。客户端是否在季列表中显示特典，还取决于 Jellyfin 的显示设置。
分集列表响应可能省略位置字段，应读取带用户上下文的单集详情；同时可检查按季返回的
分集序列是否在正确位置包含特典。

实测：2026-11-18 在 MP v3.2.8 中安装并启用插件，七集存量预览、修复和重复执行均通过；
通过正常刮削入口验证两季特典和普通集。Jellyfin 定向刷新后，单集详情位置字段正确，
第一季的 12 集正片后返回 E01–E04，第二季的 13 集正片后返回 E21–E23。

## 版本

- v3.2.0：支持按单集忽略规则保留 NFO。映射成功后按本次结果更新三项播放位置，清除无值的字段。
- v3.1.1：手动位置可覆盖或清除已有 NFO 字段。结果表显示 TMDb 和 TVDB 单集 ID，并适配亮暗主题的播放位置差异。
- v3.1.0：手动修正支持直接指定播放位置或覆盖 TVDB 查询结果。扫描明细显示「待修正」和可选中复制的 TMDb 单集 ID。
- v3.0.1：TVDB 单集返回 404 时移除对应的 TMDb 自动映射缓存，下次运行自动重新查询。
- v3.0.0：首版支持自动补全 Season 0 特典播放位置、存量 NFO 预览与修复、手动映射和持久化缓存。
