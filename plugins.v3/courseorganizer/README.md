# 按文件夹分类整理（MoviePilot V3）

读取 MoviePilot 的「设置 → 存储 & 目录」规则，扫描同一来源目录中的完整文件夹。
默认只生成安全预览；开启“自动整理符合条件的项目”后，仅自动处理识别可靠且目标媒体库明确的项目。
插件不维护另一套来源或目标目录。

## 使用条件

- 为电视剧、电影、儿童课程各保留一条明确的本地目录规则。
- 三条规则使用同一个来源目录，并开启智能重命名。
- 开启插件自动整理时，关闭同一来源目录的 MoviePilot 自动监控，避免两个任务竞争文件。
- 目录内没有正在下载的临时或缓存文件，且内容稳定后，整个文件夹才会显示。

## 操作流程

1. 先在 MoviePilot 配置存储、目录规则和智能助手，插件设置页不再重复显示这些选项。
2. 打开插件详情页重新扫描，核对建议名称、TMDB 关联和目标媒体库。
3. 需要时开启自动整理；不确定项目仍留在待确认列表，也可单项确认或批量整理。

批量任务只排队，不会并行执行；每项按顺序处理，失败项保留并继续下一项。
已关联媒体信息的项目使用 MoviePilot 原生媒体整理；无有效媒体 ID 的课程按确认后的
标题和目标媒体库规则整理。

## 智能助手

先在 MoviePilot「设置 → 智能助手」中配置并启用模型（如 DeepSeek）。插件会直接使用系统模型，
不再提供重复开关。复杂目录名会先由智能助手提取 TMDB 搜索词，搜索结果再交给规则
和智能助手复核。智能助手不可用或结果不合格时，会自动回退到本地规则与人工确认，不会
因为 AI 失败自动移动文件。
