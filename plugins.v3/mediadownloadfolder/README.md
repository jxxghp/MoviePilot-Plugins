# 媒体下载目录

在下载提交前，将同一部电影或电视剧的不同资源版本归入一个作品目录。需要 MoviePilot
V3.2.3 或更新版本；默认关闭。

例如，整理格式为：

```jinja2
{{title}} ({{year}}) {tmdb-{{tmdbid}}}/{{title}} - {{videoFormat}}{{fileExt}}
```

选择 `/downloads` 后，同一电影的 1080p 和 2160p 资源都会提交到：

```text
/downloads/示例 (2026) {tmdb-123}
```

种子自己的内部目录、文件名和下载器的布局设置保持原样。

## 配置

1. 在 MoviePilot 的目录设置中准备下载根目录。
2. 打开本插件配置，分别为电影和电视剧选择已有下载根目录。不选择某个类型时，该类型不处理。
3. 确认当前电影、电视剧整理格式中已有作品标题目录，再启用插件。

只有未指定保存路径，或明确指定了所选根目录本身的下载，会使用插件选定的根目录归组。
显式选择其它目录、自定义子目录或目录别名时，保持原来的路径规则。插件不会自动复制宿主
所有优先级、固定分类匹配和目录选择策略。多个修改下载路径的插件同时启用时，处理结果仍
遵循宿主现有事件顺序，建议只让一个插件负责同一下载的目录布局。

根目录选择保存名称、存储类型和路径的精确引用。目录被改名、删除或改路径后，请重新选择；
不会自动改用一个同名目录。根目录的类型与分类开关按当前配置生效：未限定媒体类型时可以
追加类型目录，未固定分类时可以追加分类目录，然后追加作品目录。

例如启用类型与分类目录后：

```text
/downloads/电影/亚洲/华语/示例 (2026) {tmdb-123}
```

## 支持的整理格式

插件选择文件名之前最后一个使用标题变量的目录段，忽略它之前的前缀和之后的季目录。
它复用宿主清理过的命名上下文，支持以下作品级变量：

- `title`、`en_title`、`original_title`、`title_year`
- `year`
- `tmdbid`、`imdbid`、`doubanid`、`bangumiid`、`anilistid`

缺失字段保留 Jinja 的未定义变量语义，可以使用 `default`、`is defined` 或段内 `if`。
只选择电影、电视剧的已识别作品；音乐或缺少作品名称时不接管路径。

目录段只支持以下确定性的标量和字符串过滤器：
`default`、`d`、`int`、`float`、`abs`、`round`、`string`、`format`、`lower`、`upper`、
`title`、`capitalize`、`trim`、`replace`、`length`、`count`。
随机过滤器、属性访问和集合过滤器（例如 `random`、`attr`、`map`、`selectattr`、
`groupby`、`sort`、`join`）不在支持范围内，不能借它们访问对象或改变同一作品的归组结果。

`is` 测试只支持按值判断：`defined`、`undefined`、`none`、`boolean`、`true`、`false`、
`integer`、`float`、`number`、`string`、`lower`、`upper`、`odd`、`even`、`divisibleby`、
`eq`、`equalto`、`ne`、`gt`、`greaterthan`、`ge`、`lt`、`lessthan`、`le`、`in`。
不支持 `sameas` 等对象身份测试；比较两个标题的值时可使用 `is equalto` 或 `==`，
使相同作品事实的目录不受字符串对象是否复用影响。

作品目录不能依赖季集、分辨率、发布组、原始媒体对象等资源变量，也不支持对象访问、函数
调用、循环、跨目录控制块或表达式中的斜杠。渲染结果必须是非空单层目录，不能含路径分隔符、
控制字符、盘符或上级跳转；目录名最多 255 个 UTF-8 字节，不会静默截断。

配置页面只检查模板结构，不使用示例 ID 或虚构作品数据判断模板是否可用。下载时仍按真实
媒体事实渲染并校验最终目录；若格式直接转换一个缺失的 ID，可用 `default` 或 `is defined`
明确设置缺失时的行为，否则该次下载会取消并显示实际错误。

示例电视剧格式：

```jinja2
{{title}} ({{year}})/Season {{season}}/{{title}} {{season_episode}}{{fileExt}}
```

其不同季会进入同一个 `{{title}} ({{year}})` 下载目录。若整理格式只有文件名，没有标题目录，
请先在宿主整理配置中增加作品目录。

## 错误与现有任务

启用后，作用范围内的下载若遇到根引用失效、目录读取失败或不支持的模板，会在下载器提交前
被取消；插件详情页会显示原因。其它插件已经取消的下载保留原取消原因。停用插件即可恢复
宿主原来的下载行为。

本插件不创建目录、不移动文件、不重命名种子内部文件、不修改既有下载任务或下载历史。
新任务历史继续由宿主根据下载器返回的实际路径记录；已有同 Hash 任务仍遵循下载器原路径。

配置页与详情页使用宿主的管理员权限，不额外开放 API，也不增加第三方依赖。
