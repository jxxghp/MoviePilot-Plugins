# 集数标签（EpisodeTag）

下载剧集时，自动给 qBittorrent / Transmission 的下载任务打上**集数标签**，让一个种子覆盖了哪些集一眼可见、可筛选。

> V3 版本由 V2 版（v1.3）升级而来，功能一致；类名/配置项不变，V2 用户的插件配置与标签格式数据自动继承。

## 标签格式

格式：`{前缀}{起始集:02d}[{分隔符}{结束集:02d}]`，由三个可配置项决定：

| 配置项 | 默认 | 说明 |
|--------|------|------|
| 标签前缀 | `E` | 必填，留空自动回退 `E`（与老版本无缝兼容） |
| 合并阈值 | `2` | 连续集数**超过**该值时合并为一个标签；`≤1` 时永不合并 |
| 合并分隔符 | `-` | 合并标签的起止分隔，可改为空或其他字符 |

| 场景（默认 E / 2 / -） | 标签 |
|------|------|
| 单集 | `E03` |
| 连续 2 集 | `E03`、`E04` |
| 整季 12 集 | `E01-12` |
| 补集/辅种 | 实际包含的集，如 `E03`、`E07-09` |

**修改前缀 / 合并阈值 / 分隔符保存后，会自动全量刷新所有种子的标签到新格式**；历史使用过的前缀会记录在插件数据中，旧格式标签（v1.0 范围 `E01-E12`、旧前缀）在补全/刷新时自动迁移清理。

> qBittorrent 标签不支持逗号，多集天然就是多个独立标签。

## 工作方式

- **即时打标签**：监听 `DownloadAdded` 事件，新下载加入时立即打标签。
- **集数来源（按优先级兜底）**：事件上下文的 `meta_info`（`episode_list`/`begin_episode`/`end_episode`）→ 下载历史 `episodes` 字段 → 种子标题解析 → **种子文件列表解析**（读 qB/Tr 种子内的视频文件名，覆盖无下载历史的辅种/手动种子）。
- **文件列表解析**严格匹配 `SxxExx`/`Exx` + 视频扩展名过滤，避免整季 `Complete` 标题被误判为某集。
- **补全历史**：勾选「立即补全/刷新(一次)」，给已存在的剧集种子一次性补打标签并迁移旧格式；已是当前格式的种子自动跳过，不重复写。
- **定时补全**：配置「定时补全周期」后，按周期扫描存量种子补打标签，覆盖手动加入、辅种等未经事件触发的种子。
- **电影默认跳过**：只处理电视剧 / 动漫等有集数的剧集。

## 配置项

- **启用插件**：开关。
- **跳过电影**：电影类型不打集数标签（默认开启）。
- **立即补全/刷新(一次)**：触发一次全量补全/格式刷新，执行后自动关闭。
- **定时补全周期**：crontab 格式（如 `0 3 * * *` 每天凌晨 3 点），留空则不定时执行。
- **包含标签(可选)**：逗号分隔，仅处理命中任一标签的存量种子；**留空则处理全部**。
- **排除标签(可选)**：逗号分隔，命中任一标签的种子直接跳过。
- **下载器**：选择要作用的 qBittorrent / Transmission 实例（可多选）。
- **标签前缀 / 合并阈值 / 合并分隔符**：见上文标签格式。

> 包含/排除标签仅影响存量扫描（定时补全、立即补全），不影响新下载任务的即时打标签。

## 与其它插件共存

本插件只追加/迁移自己的集数标签，不影响其它标签，可与「下载任务分类与标签（DownloadSiteTag）」等打标签插件同时启用。

- qBittorrent：`set_torrents_tag` 追加缺失标签、`delete_torrents_tag` 移除旧格式标签。
- Transmission：合并去重后整体写入，避免覆盖。
