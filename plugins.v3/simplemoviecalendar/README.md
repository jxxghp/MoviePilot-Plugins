# 简单观影日历

查看电影数字版、蓝光和国内电影流媒体上线时间，可手动添加到MP首页仪表盘方便查看。适用于 MoviePilot V3.2.3 及更新的 V3 版本。

## 安装与启用

在「插件市场」搜索并安装「简单观影日历」，然后在「我的插件」打开插件设置，开启「启用简单观影日历」并保存。

## 查看排期

打开插件详情页，可分区查看「即将发行」和「最近发行」。电脑上自动多列排列，手机上单列显示。点击影片下方「完整排期」可在当前页面展开各版本、平台和具体时间。

- 在「探索」中选择「简单观影日历」来源，浏览即将发行和最近发行的电影。打开影片详情可查看各平台、各版本的排期，日期按北京时间显示。
- 在仪表板设置中手动添加「简单观影日历 · 即将发行」组件。横向滑动海报可浏览更多影片，查看下一次发行的日期、倒计时、发行类型以及豆瓣和 IMDb 的评分与评价人数。

排期默认每 30 分钟刷新。也可以在插件详情点击「立即更新日历」。
