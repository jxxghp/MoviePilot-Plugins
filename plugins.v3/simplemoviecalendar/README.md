# 简单观影日历

在 MoviePilot 中查看电影的数字发行、流媒体上线和蓝光发行排期。适用于 MoviePilot V3.2.3 及更新的 V3 版本。

## 安装与启用

在「插件市场」搜索并安装「简单观影日历」，然后在「我的插件」打开插件设置，开启「启用简单观影日历」并保存。

## 查看排期

- 在「探索」中选择「简单观影日历」来源，浏览即将发行和最近发行的电影。打开影片详情可查看各平台、各版本的排期，日期按北京时间显示。
- 在仪表板设置中手动添加「简单观影日历 · 即将发行」组件。横向滑动海报可浏览更多影片，查看下一次发行的日期、倒计时、发行类型以及豆瓣和 IMDb 的评分与评价人数。点击卡片可打开完整排期。

排期默认每 30 分钟刷新。也可以在插件详情点击「立即更新日历」。
