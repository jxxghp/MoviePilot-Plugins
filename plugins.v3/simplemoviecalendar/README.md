# 简单观影日历 0.1.5

MoviePilot V3 只读发行日历插件，需要 MoviePilot V3.2.3 或更新的 V3 版本。

启用后，“探索”新增“简单观影日历”来源。首页组件在仪表板设置中手动添加；插件不改动现有布局。

仪表板中的海报横向排列，卡片较窄时可横向滚动。海报下依次显示片名、豆瓣与 IMDb 评分及评价人数、下一次发行的日期和倒计时，以及去重后的发行类型。点击卡片可打开完整排期。

数据来自 https://ys.chenhao.net/calendar.json ，无需密钥。默认每 30 分钟更新一次，失败时保留最后成功缓存；首次获取失败可在插件详情点“立即更新日历”。具体日期按北京时间分组，完整多平台／版本排期在影片详情的介绍中查看，也可打开公开日历。

首版不提供直接订阅功能。探索卡片／详情仍可能显示 MoviePilot 自带的搜索和订阅按钮，这些是宿主界面，尚未验证与本插件来源兼容，请使用本插件查看排期。


在插件市场搜索「简单观影日历」，安装后在「我的插件」启用并保存。
