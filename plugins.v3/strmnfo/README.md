# STRM媒体信息补全

MoviePilot 整理入库后，自动从 `.strm` 文件名里的技术标签生成同名的
`.strm.nfo`（Kodi streamdetails 格式），供 Emby 的 STRM Probe NFO 插件
读取入库，让媒体播放器显示分辨率 / 编码 / HDR / 音频等媒体信息。

**全程只读文件名，不访问云盘、不下载任何文件。**

## 怎么用

1. 插件配置里打开**启用插件**，监控目录填 MoviePilot 容器内能看到的
   `.strm` 目录（默认 `/media/Link`），点保存；
2. 第一次使用时打开**立即运行一次**，保存后 3 秒开始全量扫描，把已有的
   `.strm` 一次性补齐；
3. 以后每次整理完，插件自动给新入库的 `.strm` 生成 nfo；每 6 小时还会
   全量扫描一次兜底。也可以发 `/strmnfo_scan` 命令手动触发一次全量扫描。

## Emby 侧（必须做，否则 nfo 不生效）

1. Emby 装好 STRM Probe NFO 插件（4.10.1.0+），在它的设置里**选上所有含
   `.strm` 的媒体库**并保存；
2. Emby 仪表板 → 计划任务 → 运行 **Apply pending .strm.nfo sidecars**，
   把安装前就已入库的条目补读进去；
3. 之后新增的 nfo 由 Emby 媒体库实时监控或 STRM Probe NFO 的每日定时任务
   自动处理。完成后在 Emby 里打开一部片子，看媒体信息是否显示正常。

## 能识别什么

分辨率（2160p/1080p 等，也认文件名里显式的 `3840x2160`）、视频编码
（HEVC/H.264/AV1 等）、HDR（DV 优先于 HDR10/HLG/SDR）、多轨音频
（TrueHD/DTS-HD MA/DDP/EAC3/AC3 等，每轨各自带声道）、声道（5.1/7.1，
接受 `DDP5.1` 这种无分隔写法）、帧率、码率、音轨语言、字幕。

## 注意

- 文件名里没有任何技术标签的文件生成不了（比如只有片名 + 集数），只能
  留空或以后再探测。
- 分辨率是标称值（`2160p` → `3840x2160`），真实探测才会给精确裁切值。
- 默认不覆盖已有 `.strm.nfo`，重复运行安全；想重新生成就打开
  「覆盖已有 .strm.nfo」。
- 插件详情页能看到累计生成 / 跳过 / 无法解析 / 失败的统计和失败文件列表。
