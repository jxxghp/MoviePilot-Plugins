# 通知高清图片

MoviePilot 在发送消息通知时，默认使用 TMDB w500 尺寸的图片（500px 宽），在飞书等渠道的卡片中显示会偏模糊。

本插件通过劫持消息发送链路（`post_message`），在发送前将通知图片地址从 `w500` 升级为 `w1280` 高清尺寸，显著提升推送海报/背景图的清晰度。不修改 MoviePilot 本体代码，插件升级与卸载均不影响系统。

## 功能

- 自动将通知中的 TMDB 图片 URL 从 `w500` 升级为 `w1280`
- 支持所有通知类型（整理入库、资源下载、订阅、站点、手动处理等）
- 纯内存字符串替换，无网络请求，无性能开销

## 使用

1. 安装并启用插件（设置 → 插件 → 通知高清图片 → 启用）
2. 之后所有消息通知自动使用高清图片

## 说明

- 仅在图片 URL 包含 `/t/p/w500/` 时进行替换，其余情况原样发送
- 图片最终由消息渠道（如飞书）下载上传，需渠道本身支持上传图片
