# PT数据统计

这是 MoviePilot V2/V3 共用实现：V2 直接加载，V3 通过官方 V2 插件向后兼容机制加载。
当前与日级历史直接读取 MoviePilot 的 `SiteUserData`；插件数据目录中的独立 SQLite
只保存刷新时产生的小时快照，不复制 MoviePilot 的日级历史，也不向主数据库增加插件表。

## 数据口径

- 上传、下载、分享率、魔力和做种数等主数据源仅为 MoviePilot 的 `SiteUserData`；不抓取 PT 站点、不读取下载器。
- 日期和通知 Cron 使用 MoviePilot 配置的服务器时区。
- 插件不设置独立采集间隔；MoviePilot 刷新站点后，插件通过 `SiteRefreshed` 事件读取其已保存结果。
- 当日上传/下载 = 当日累计值 − 严格前一自然日累计值；缺少前一天成功快照时显示“基线不足”。
- 累计值下降时负增量按 0 展示，不把更早日期当作前一天补算。
- 可选开启插件自带的 PTD CookieCloud 兼容接收端，直接接收 PTD 备份并补充“时魔”和“做种积分”；时魔与做种积分增速分别读取，绝不混用。其他 PTD 字段一律不导入。未启用 PTD 时，预估时魔仍使用最近两次成功 MP 每日快照估算。
- 日级历史直接查询 MP 已保存的数据，不复制、不修改 MP 原始数据；本地仅保留小时快照。
- PTD 加密备份和导入结果分别使用固定存储键整体覆盖，只保留最新一份，不写入插件历史表。

## 功能

- **数据总览**：累计和今日指标、可整框点击选择月份/日期的站点上传下载分布，以及无需横向滚动的响应式站点卡片；加入时间只显示到日，魔力与预估时魔分别展示，并可按 MoviePilot 站点优先级、加入时间（最早优先），或按上传、下载、魔力、做种数、做种体积降序排列。
- **数据统计**：按日、周、月查看站点流量；点击站点后上方曲线切换为该站点数据，并在站点行内展开所选周期的历史明细。
- **养老进度**：十二大采用按真实加入时间排列的紧凑横向里程碑，已加入站点仅显示图标和名称，未加入节点保持匿名；左侧站点列表支持按站点优先级、加入时间（最早优先）、养老进度、累计上传、累计下载或站点名称排序，高度随站点数量自适应，右侧明细随内容完整展开并由页面统一滚动，集中展示当前上传、下载和分享率、从 User 开始直至最高等级的路线、下一等级条件、保号目标与可展开的完整等级要求。等级路线与要求表仅展示各等级门槛和说明。注册时间未合格时显示实际累计天数，合格后仅显示“达成”。内置等级数据由 PTDepilerMp 固定提交中的 234 份站点规则生成，站点名称、域名、来源标识和别名共同参与匹配；VIP 规则和设置页手动选择的特殊会员站点显示“富贵养老”。任选条件按“满足任一项”计算，MoviePilot 未提供的发布数、平均做种时间等指标明确显示为数据未提供。
- **自定义等级规则**：设置页可上传 JSON 规则文件，补充新站点或覆盖匹配的内置规则；支持站点别名、域名、等级别名、VIP 等级、任选条件、做种体积、发布数和平均做种时间，上传内容经结构和数值校验后随插件设置保存，不会发送到外部服务。
- **仪表板**：仅显示今日有有效上传或下载增量的站点，随 MP 卡片尺寸适配并支持内部滚动。
- **每日通知**：标准五段式 Cron；每个服务器自然日最多一次，不补发，无数据站点不通知。
- **PTD CookieCloud**：设置页会生成本插件的 CookieCloud 兼容接收地址；在 PTD 中填写该地址以及相同的专用 UUID、密码和可选 Headers 即可，不需要启用 MoviePilot 内置 CookieCloud。PTD 备份需勾选“用户信息”；收到备份后立即解析并覆盖旧数据。
- **运行日志**：记录 PTD 连接检测、备份接收、解密解析、站点匹配、覆盖成功及失败原因；密码、完整 UUID、鉴权值和密文不会写入日志。

所有用户可见页面和通知均不展示站点域名；域名仅在后端参与等级规则匹配。十二大按 MP 站点名称自动识别，不提供手工域名绑定；名单包含皇后和听听歌，不再包含 U2。

## 构建前端

```shell
pnpm install
pnpm build
```

构建产物位于 `dist/assets`，模块联邦名称及后端插件类 ID 均为 `PTDataStatistics`。
