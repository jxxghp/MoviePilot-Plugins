# 站点数据统计

## PB 级流量的精度提示

部分站点页面只显示三位小数的 PB 累计流量，最小显示步长为
`0.001 PiB = 1.024 TiB`（插件显示约 `1.02T`）。即使每天有上传，页面也可能多日
不变，然后一次跳变 `1.02T`。这种差值不能代表精确的单日流量。

从 1.9.6 起，插件对两期有效读数均位于 PB 三位小数格点、均达到 1000 TiB
且未回退的上传或下载字段标记 `≈`。通知、汇总、图表和明细表同步提示精度；
读数不变时保留站点通知并显示“实际增量未知”，仪表盘的提示区域也会保留该站点。
同一天内相同通知仍只发送一次。

这是**疑似舍入提示**：数据库没有记录原始页面单位和精度，仅靠字节数不能严格区分
舍入值与恰好落在相同格点的精确 API 数据。缺少前一期数据、刷新失败或读数回退时
不作此推断；不在该格点的 API 数据以及 TB/GB 级数据保持原有展示。

插件不修改历史数据，不隐藏跳变值，也不按跳变日期推算日均。对于按最近值舍入的
两个累计读数，其差值误差可达一个显示步长；多个站点的汇总误差还可能叠加。
要获得准确单日增量，需要站点提供更精确的页面数据或字节级 API。
