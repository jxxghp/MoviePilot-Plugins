# 站点自动签到

可分别选择需要签到和模拟登录的站点；“全部”会在每次运行时包含当前所有站点。

签到只有在站点返回明确的完成状态、签到奖励或接口业务成功结果时才报告成功。
登录成功、HTTP 200、签到按钮消失、跳回签到页，都不能单独证明已经签到。
部分站点的跳转或数字响应会回读页面确认；验证码、页面变化或未知响应会报告
“签到失败，未确认签到结果”，请到站点检查是否需要手动操作。

失败和未确认结果会在下一次任务运行时重试，不受自定义重试关键词限制。
重试关键词仍可额外选中其他结果；未填写关键词时保留每次重新执行全部已选站点的行为。

详情页保存实际返回结果，不再把“执行过”显示为“已签到”。升级前的成功记录标记为
历史结果未确认，当天缺少明确结果的旧记录会重新执行验证；仅模拟登录的站点会明确标记“未执行签到”。
签到和登录历史保留含当天的最近 14 天。
