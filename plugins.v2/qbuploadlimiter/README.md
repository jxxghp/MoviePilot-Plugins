# MoviePilot QB 上传限速插件

这是一个只支持 MoviePilot V2 插件市场结构的分享率限速插件。下载器下拉支持选择 MoviePilot 中已配置并启用的 qBittorrent / Transmission 下载器。

## 功能

- 检测所选下载器中的种子分享率（分享率 = 上传量 / 下载量）
- 仅对已下载完成的种子按分享率限速：种子分享率达到设定阈值（正整数）后，自动将该种子的上传速度限制为指定值（KB/s）；qBittorrent 已启用全局上传限速且该值更低时，自动采用全局限速
- 支持按站点单独设置分享率阈值；对应站点使用单独阈值，未配置或无法识别站点时回退使用全局阈值
- 支持启用后定时检测并持续应用限速，防止被其他插件或手动操作覆盖
- 支持立即运行一次
- 支持按站点筛选：勾选站点后，仅对所选站点下载的种子执行分享率限速（留空则对所有种子生效）
- 支持监控超时取消：种子下载完成后持续监控其上传速度（不限是否达到分享率阈值），若上传速度持续低于限速值达到设定秒数，或限速后持续限速/上传速度低于限速值 80% 达到设定秒数时，自动取消监控并立即将该种子恢复为不限速（此后插件不再干预该种子）
- 限速通知：状态变化时逐条发送通知（可多选通知渠道），包括「限速」「取消限速」「AI 接管」「AI 取消接管」四类，内容为「站点所下的种子已限速多少KB/s / 已取消限速 / AI已接管 / AI已取消接管」，站点、种子、限速值加粗显示
- 限速所有权：仅对「本插件实际设置过限速」的种子登记待恢复；种子当前限速已等于目标值且并非本插件所设时不会认领，停用/卸载时不会误将外部设置的限速恢复为不限速
- 状态持久化：待恢复记录与已取消监控记录在每次检测后立即落盘，跨保存配置、重启插件保留，确保已限速种子停用/卸载时可兜底恢复、已取消监控种子不会因重新初始化被再次限速
- 兜底恢复重试：停用/卸载时若下载器短暂离线导致恢复失败，插件会自动定时重试（下载器长时间离线时持续重试，不提前终止），下载器重连后无需重新启用插件即可恢复不限速；启用状态下每轮检测也会顺带重试「已取消监控但恢复失败」的种子，且覆盖所有存在待恢复记录的下载器（含已从插件选择中移除的下载器），上传速度填 0 时同样会重试
- 停用或卸载插件时自动恢复本插件限速过的种子的上传速度为不限速（已取消监控的种子在取消时已立即恢复，插件不再干预）

## 安装

将本仓库配置到 MoviePilot V2 插件市场后，在插件市场中安装「QB上传限速」。

仓库目录结构：

    plugins.v2/qbuploadlimiter/__init__.py
    package.v2.json
    icons/Qbittorrent_A.png

## 配置说明

- 启用插件：启用后立即检测一次，并按配置间隔定时检测。
- 立即运行一次：保存后 3 秒执行一次，不要求保持启用；首次点击会自动发送一次测试通知，之后重复点击不再发送。
- 全局分享率阈值：种子的分享率 = 上传量 / 下载量；当种子分享率 ≥ 阈值（正整数，不允许填 0）时限制其上传速度。未配置站点单独阈值时使用该值。
- 按站点单独分享率阈值：可选配置，一行一个，格式为「站点名称=正整数阈值」，例如：

      站点A=3
      站点B=5

  站点名称不区分大小写，重复站点以最后一项为准。对应站点使用单独阈值；未配置、配置无效或无法识别站点时回退使用全局阈值。若同时启用了站点筛选，仍只处理筛选范围内的站点。
- 上传速度（KB/s）：达到阈值后的种子上传速度上限，默认 2000。qBittorrent 已启用全局上传限速时，会与此值取较小者：全局值更低时采用全局值，插件配置更低时仍采用插件配置；qB 全局值为 0（不限速）及 Transmission 下载器均使用插件配置。0 表示分享率达到阈值后不做限速处理。
- 数值校验：上传速度、全局/站点分享率阈值、定时检测间隔与两个监控超时均要求为整数（不允许小数）；上传速度允许填 0（达到阈值后不做限速处理），两个监控超时允许填 0（不启用对应监控功能），全局和站点分享率阈值必须 ≥ 1，定时检测间隔最短 10 秒。
- 定时检测间隔（秒）：默认 30 秒，最短 10 秒，建议设置 30 秒以上。用于持续监控种子分享率，达到阈值后自动限速，并防止限速被其他插件或手动操作覆盖后失效。
- 下载完成后监控超时（秒）：种子下载完成后，插件持续监控其上传速度；上传速度持续低于限速值达到设定秒数时，取消监控并立即恢复该种子不限速（插件不再干预该种子），速度回升到限速值即重新计时；0 表示不启用。
- 限速后取消监控超时（秒）：种子被限速后，持续限速或上传速度低于限速值 80% 达到设定秒数时，取消监控并立即恢复该种子不限速（插件不再干预该种子）；种子被手动或其他插件改为非目标限速时会重新计时，不会按旧计时误判超时；0 表示不启用。
- 下载器：请选择 MoviePilot 系统设置中已配置并启用的 qBittorrent 或 Transmission 下载器。
- 站点：可多选 MoviePilot 系统设置中已配置并启用的站点；留空表示对所有种子生效，勾选后仅对所选站点下载的种子进行限速。站点识别优先使用 MoviePilot 下载历史中的站点记录，其次通过种子 tracker 域名识别，再匹配种子标签/分类中的站点名。
- 发送通知：可多选 MoviePilot 系统设置中已配置并启用的通知渠道；留空表示不发送通知。限速、取消限速、AI 接管、AI 取消接管等状态变化会逐条发送通知（沿用同一模板），点击通知直达插件详情页。插件通知不受 MoviePilot 通知渠道的「通知场景」开关限制，勾选的渠道必定收到。
