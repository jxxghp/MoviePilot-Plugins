# EMOS 上传插件

将媒体文件上传到 EMOS（Emby 资源站上传分发系统）的 MoviePilot V2 插件。

## 功能特性

- 🔄 **下载完成自动上传**：定时轮询下载器，种子【下载完成】瞬间自动上传源文件到 EMOS
- 🎯 **服务器端识别**：通过 EMOS 接口自动识别文件，匹配剧集信息
- 📊 **版本对比**：上传前检查已有资源版本（分辨率 + 文件大小），相同版本跳过
- ⚡ **分片并发**：多分片并发上传，最大化吞吐
- 🚫 **跳过标签**：种子带刷流/保种等标签时直接按种子标签过滤，不上传
- 📝 **上传历史**：记录最近 50 条上传记录
- 🔔 **通知集成**：上传结果通过 MoviePilot 通知渠道推送

## 配置说明

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 启用插件 | 开启/关闭插件 | 关闭 |
| 上传模式 | ask=询问确认 / silent=自动上传 | ask |
| 跳过标签 | 种子命中这些标签则不上传（逗号分隔） | 刷流,保种,seedbox |
| 轮询间隔 | 下载器轮询间隔（秒），检测到新完成的种子即上传 | 60 |
| 通知渠道 | ask 模式确认消息发送渠道（多选） | 留空=不发送通知 |
| Token 文件路径 | EMOS token 文件路径 | /opt/data/creds/emos_token |
| 目标分片数 | 上传时的分片数量 | 24 |
| 并发数 | 并发上传线程数 | 16 |

## 触发方式

插件**定时轮询已选下载器**（MoviePilot 无「下载完成」事件），检测到种子下载完成（qBittorrent `progress=1` / Transmission `percent_done=1`）即触发上传，无需等待入库/刮削。

因此：

- 上传的是**下载完成的种子源文件**（下载目录里的原始文件），并非媒体库文件
- 不受整理策略（复制/硬链接/移动）影响——下载完成时文件必然还在下载目录
- 整季/多文件种子会自动逐个上传全部媒体文件

## 上传模式

插件支持两种模式，在配置页「上传模式」中切换：

### ask（询问模式，默认）

下载完成后自动识别并汇报，**等待用户确认后才上传**：

1. 轮询检测到种子下载完成 → 开始识别
2. 调用 EMOS 识别接口，获取剧集信息（剧名 / 集数 / 大小 / 分辨率）
3. 检查并对比 EMOS 已有资源版本
4. 通过通知发送「待确认上传」报告，等待用户确认后才执行上传

同一种子下载的多个文件合并为**一条待确认通知**，同一剧名+季仅一行，只显示总大小。

版本对比结论：
- 无资源 → 提示「将作为首个版本上传」
- 版本不同 → 提示「版本不同，可上传补充」
- 版本相同 → 自动跳过并提示「无需重复」

**确认命令**（通过 MoviePilot 远程命令发送）：

| 命令 | 说明 |
|------|------|
| `/emos_confirm 传` | 上传全部待确认文件 |
| `/emos_confirm 传 2` | 只上传编号 2 的文件 |
| `/emos_confirm 不传 2` | 跳过编号 2 的文件 |
| `/emos_status` | 查看状态和待确认列表 |

> 每个待确认文件都有独立编号（如 [1]、[2]），可单独或批量确认。

### silent（静默模式）

下载完成后自动识别并对比版本，**无需确认直接上传**，不打扰用户。

## 版本对比规则

只比较两项：

| 比较项 | 规则 |
|--------|------|
| 分辨率 | 完全匹配（2160P / 1080P / 720P / 480P） |
| 文件大小 | 差异 ≤ 5% 视为相同 |

两项都匹配 → 判定为相同版本，跳过上传。

## 通知渠道

ask 模式发出的「待确认上传」报告、上传结果等通知发送到哪：

- **指定渠道**（多选）：只发送到所选渠道（如只发 Telegram）
- **留空**：不发送任何通知

可在配置页「通知渠道」中选择。

> ⚠️ 注意：ask 模式靠通知消息进行确认，若「通知渠道」留空则收不到待确认消息，无法确认上传。建议配合 silent 模式或选定一个通知渠道使用。

## 跳过标签

默认跳过带「刷流 / 保种 / seedbox」标签的种子，不参与 EMOS 上传。

识别方式：轮询时**直接读取下载器中该种子的标签**（qBittorrent `tags` / Transmission `labels`），命中配置的「跳过标签」即跳过，不再上传其任何文件。

可在配置页「跳过标签」中修改（逗号分隔），留空表示全部处理。

## 上传流程

1. 定时轮询下载器，检测到下载完成的种子
2. 读取种子标签，命中跳过标签则忽略
3. 获取该种子下载的媒体文件（源文件）
4. 调用 EMOS 识别接口，获取剧集信息
5. 检查 EMOS 已有资源版本
6. 版本对比：无资源/版本不同 → 可上传；版本相同 → 跳过
7. 分片并发上传到 EMOS 存储
8. 完成合并，保存记录
9. 发送通知

## API 接口

| 接口 | 说明 |
|------|------|
| `GET /api/v1/plugin/EmosUpload/status` | 获取状态、待确认列表和上传历史 |
| `GET /api/v1/plugin/EmosUpload/pending` | 获取待确认上传列表 |

## 远程命令

- `/emos_status` - 查看上传状态和待确认列表
- `/emos_confirm 传 [编号]` - 确认上传
- `/emos_confirm 不传 [编号]` - 跳过上传

## 聚合通知

一个种子（如整季）下载的多个文件合并为**一条通知**，不再逐个文件刷屏：

- **同一剧名 + 季**合并为一行，只显示总大小（如 `绝命毒师 S01：45.2GB`）
- **ask 模式**：一条待确认清单，回复一次确认全部
- **silent 模式**：一条完成汇总（成功 / 失败 / 跳过统计）

- 新增聚合通知：一个种子的多个文件合并为一条通知
- 同一剧名+季仅一行，只显示总大小
- ask 模式一次确认全部，silent 模式一条完成汇总

### v2.0.0
- **重大变更**：触发方式由「入库完成事件」改为「轮询下载器，下载完成即上传」
- 上传下载目录的【源文件】，不受整理策略（复制/硬链接/移动）影响
- 跳过标签改为直接读取下载器种子标签，识别更可靠
- 新增「轮询间隔」配置项

### v1.3.0
- 重要修复：整季/多文件入库时只上传第一个文件、其余漏传
- 现改为遍历全部源文件（TransferInfo.file_list）逐个上传

### v1.2.2
- 修复版本检查接口传参：/api/upload/video/base 改用 URL query 传参

### v1.2.1

### v1.2.0
