# 动态企微可信IP（V2 世代）

这里是 1.0.13 的 V2 实现，只用于 MoviePilot v2 宿主，已停止功能更新。
V3 宿主请使用 2.0.2，功能说明见 [V3 版文档](../../plugins.v3/updatewechatip/README.md)。

需要说明一点：MoviePilot v2 的插件市场没有 README 探测，也没有「查看文档」入口，
本文件只在仓库里可读，不会出现在插件界面。

## 与 2.0.2 的行为差异

- 判定是否需要更新时只读**第一个**应用ID 的白名单，但写入会覆盖配置里列出的全部应用ID。
- 写入是否成功按响应文本里有没有 `err` 判断，不解析 errorcode。
- 登录二维码图片落盘在插件数据目录的 `WeChatQr.jpg`；2.0.2 改为只在内存保留。
- `POST/GET /plugin/UpdateWeChatIp/UpdateIP` 在 V2 侧是 GET，且只执行、不返回写入结果。
- 没有自定义 IPv4 查询接口；按应用逐个校验、写入结果按应用汇总成三种通知措辞，都是 2.0.2 才有的能力。
- 登录失效的重复提醒在 V2 会遍历所有通知渠道类目；2.0.2 只发给实际已启用的渠道。

其余用法（`/update_wechat_ip` 取二维码、6 位短信验证码、检测周期 cron、失败 3 次后 30 分钟降频）
与 V3 版一致，直接看 V3 文档即可。
