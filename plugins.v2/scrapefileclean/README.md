# MoviePilot 源文件联动清理插件

MoviePilot V2 插件，专为**手动清理下载目录**场景设计：手动删除源文件（下载目录中的原始媒体文件）后，插件自动联动清理媒体库中对应的**硬链接文件**、**刮削文件**（元数据、图片、字幕）与**转移记录**，保持媒体库与下载目录状态一致，避免残留失效文件。

适用场景：
- 手动删除下载目录中的源文件，媒体库中的硬链接文件自动被清理
- 联动清理被删除文件同名的刮削文件（.nfo、图片、字幕等元数据）
- 联动删除对应的转移记录，避免历史记录残留
- 支持空目录清理、延迟删除（防止媒体重整理导致误删）与通知

设计参考 [DzAvril/MoviePilot-Plugins](https://github.com/DzAvril/MoviePilot-Plugins) 的清理媒体文件插件（removelink），本插件为独立实现，聚焦硬链接联动清理场景。

## 功能

- 监控源目录与媒体库目录，记录每个文件的 `(dev, inode)` 以识别硬链接关系
- 源文件删除后，自动删除媒体库中所有指向同一文件实体的硬链接文件
- 联动清理被删除文件同名的刮削文件（.nfo/.jpg/.srt 等，后缀可自定义）
- 联动删除转移记录（按目标路径或源路径匹配）
- 自动清理只剩刮削文件或完全为空的目录
- 可选联动删除种子（需安装插件[下载器助手]并打开监听源文件事件）
- 可选延迟删除（默认 30 秒），防止媒体重整理/重命名导致的误删
- 支持排除目录、过滤关键字、发送通知

## 安装

将本仓库配置为 MoviePilot V2 插件市场后，在插件市场中安装「源文件联动清理」。

仓库目录结构：

    plugins.v2/scrapefileclean/__init__.py
    package.v2.json
    icons/clean.png

## 配置说明

- **启用插件**：开启后启动目录监控并全量建立文件状态。
- **监控目录**：每行一个目录。源目录（下载目录）和媒体库目录（硬链接目录）都需要添加，
  插件才能识别源文件与硬链接的对应关系。
- **不删除目录**：命中其中的文件不会被删除。如需实现「删除硬链接时不删除源文件」，
  可把源文件目录配置到这里。
- **过滤关键字**：路径包含关键字的文件不处理。
- **清理刮削文件**：删除媒体文件时联动清理同名的 .nfo、图片、字幕等元数据文件。
- **自定义刮削文件后缀**：每行或逗号分隔，会与内置后缀一起参与清理。
- **删除转移记录**：删除文件时清理对应的转移记录。
- **联动删除种子**：需安装插件[下载器助手]并打开监听源文件事件。
- **延迟删除**：删除事件进入队列，等待指定时间后再次校验再执行，防止误删；停止或停用插件时未到期的延迟任务会被放弃，不会提前执行。
- **发送通知**：清理完成后发送站点消息通知。

## 注意事项

- 清理刮削文件会删除相关的 .nfo、.jpg 等元数据文件，请谨慎开启。
- 插件不会自动删除不在监控目录中的文件；删除硬链接时如需保留源文件，请把源目录
  加入「不删除目录」。
