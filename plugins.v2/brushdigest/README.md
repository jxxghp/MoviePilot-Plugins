# 刷流汇总（BrushDigest）

把站点刷流的新增/删除汇总成一条周期通知，替代每个种子一条的逐条推送。

- **只做通知汇总**，不刷流、不删种、不改下载任务，随时可以关掉，不影响刷流本身。
- 兼容单任务版 `BrushFlowLowFreq` 与 多任务版 `BrushFlow`，统计增量由插件快照差值算出。
- 数据来源自动检测，配置页下拉选择即可，不需要手填插件 ID。
- 支持「立即推送一次」自测、无变化不推送、显示流量增量。

**使用前必读**：请先到原刷流插件里关掉「发送通知」，否则每个种子仍会单独推送，汇总就失去意义了。

```ini
0 */2 * * *    # 跟着刷流节奏，每 2 小时一条
0 9 * * *      # 每天早上 9 点一条，最省事
```
