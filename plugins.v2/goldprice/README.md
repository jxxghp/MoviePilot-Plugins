# 金价日报

每日定时抓取**金店零售价**(周大福/老凤祥/周生生/六福/老庙/菜百/金至尊)、**银行纸黄金**(工行/建行等)、**大盘金价**(国际/上海现货)，排版后通过 MoviePilot 已配置的通知渠道(微信/企业微信/WxPusher/Telegram…)推送。

## 数据源

| 数据 | 来源 | 说明 |
|---|---|---|
| 金店零售价 + 大盘价 | `https://www.ip138.com/gold/` | 服务端渲染 HTML 表格 |
| 银行纸黄金 | `https://www.jinjiabiao.com/papergold` | 服务端渲染 HTML 表格 |

均为免费公开页面，**无需 API Key、无 JS 渲染**，解析稳定。数据源为非官方公开页面，若站点改版导致解析失败，插件会推送「获取失败」提示而非静默。

## 配置项

- **启用插件**
- **立即运行一次**：保存后立刻抓取推送一次，便于验证渠道
- **推送时间**：5 段 cron，默认 `30 9 * * *`(每天 9:30)
- **消息类型**：留空默认归入「插件」通知类型
- **推送大盘金价 / 金店零售价 / 银行纸黄金**：三个独立开关
- **关注金店**：逗号分隔，留空=全部；填写则只推这些并按填写顺序排列

## 注意

- 推送走系统通知渠道，需先在 MoviePilot「设置 → 通知」启用微信渠道(企业微信 / WxPusher 等)。
- 品牌金价一般上午更新，cron 可自行调整。
