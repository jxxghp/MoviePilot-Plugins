# 集数标签（EpisodeTag）

下载剧集时，自动给 qBittorrent / Transmission 的下载任务打上**每集独立标签**，让一个种子覆盖了哪些集一眼可见、可筛选。

## 标签格式

**每集拆成独立标签，不使用范围：**

| 场景 | 标签 |
|------|------|
| 单集 | `E03` |
| 整季包 | `E01`、`E02`、`E03`、… 每集一个标签 |
| 补集/辅种 | 实际包含的集，如 `E03`、`E07` |

可在配置中设置**标签前缀**，例如填 `集数-` 后每个标签变为 `集数-E01`、`集数-E02`。

> qBittorrent 标签不支持逗号，所以多集天然就是多个独立标签，正合本插件设计；旧版本打过的范围标签（如 `E01-E12`）会在补全时自动拆开迁移。

## 工作方式

- **即时打标签**：监听 `DownloadAdded` 事件，新下载加入时立即打标签。
- **集数来源（按优先级兜底）**：事件上下文的 `meta_info`（`begin_episode`/`end_episode`）→ 下载历史 `episodes` 字段 → 种子标题解析 → **种子文件列表解析**（读 qB/Tr 种子内的视频文件名，覆盖无下载历史的辅种/手动种子）。
- **文件列表解析**严格匹配 `SxxExx`/`Exx` + 视频扩展名过滤，避免整季 `Complete` 标题被误判为某集。
- **补全历史**：勾选「立即补全历史(一次)」，给已存在的剧集种子一次性补打标签，并把旧的范围标签拆成每集。
- **电影默认跳过**：只处理电视剧 / 动漫等有集数的剧集。

## 配置项

- **启用插件**：开关。
- **跳过电影**：电影类型不打集数标签（默认开启）。
- **已标记则跳过**：补全时若任务已是每集标签则跳过（默认开启）。
- **立即补全历史(一次)**：触发一次全量补全，执行后自动关闭。
- **下载器**：选择要作用的 qBittorrent / Transmission 实例（可多选）。
- **标签前缀**：可选。

## 与其它插件共存

本插件只追加/迁移集数标签，不覆盖其它标签，可与「下载任务分类与标签（DownloadSiteTag）」等打标签插件同时启用。

- qBittorrent：`set_torrents_tag` 追加、`delete_torrents_tag` 移除旧范围标签。
- Transmission：`set_torrent_tag` 合并后整体写入，避免覆盖。
