# 播放限速

外网播放时，按播放码率为下载器分配剩余上传带宽。

- **按比例**：按所填比例分配；留空时均分。
- **按下载器顺序**：先满足列表靠前的下载器，后面的先让出带宽。可用于同时运行 PT、公开 BT 下载器。
- **下载器上传上限**：每行填写 `下载器名称=KB/s`。TR 使用十进制 KB/s，qB 使用 KiB/s；未填写时保留启用前的上传上限。
- **智能限速上行带宽**：填写可稳定使用的上行带宽，单位 Mbps。
- **预留带宽、播放带宽系数**：给其它流量和播放突发留出余量。

开播、恢复或拖动后的15秒及码率缺失时优先让出上传。暂停或停止后等待所设时间，按所设步长逐步恢复；未配置下载限速时保留下载设置。停用时恢复插件修改前的设置，不覆盖期间手动修改的上传值。

可选“按播放片段预留”：Emby 直接播放时，后台读取本地文件附近的数据包，按未来一分钟内的30秒窗口估算需求，并留15%余量。媒体服务器与MP的路径不同时，每行填写 `媒体服务器路径=MP路径`。单次探测超时20秒，输出上限16MiB，只同时探测一个片段；不可读、未完成或转码时使用媒体服务器码率和播放带宽系数。

切换探测区间时复用仍有效的数据，避免扫描期间反复退回保守限速。文件属性在后台读取，停用时结束探测进程。日志记录片段估算、回退原因和播放预留带宽。

分段预测不测量客户端缓存或实际网络吞吐。经代理访问时，应核实不限速地址范围，避免远程播放被识别成内网播放。
