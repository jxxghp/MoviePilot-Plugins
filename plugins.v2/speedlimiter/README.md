# 播放限速

外网播放时，按播放码率为下载器分配剩余上传带宽。无需配置大模型。

- **按比例**：按所填比例分配；留空时均分。
- **按下载器顺序**：先满足列表靠前的下载器，后面的先让出带宽。可用于同时运行 PT、公开 BT 下载器。
- **下载器上传上限**：每行填写 `下载器名称=KB/s`。TR 使用十进制 KB/s，qB 使用 KiB/s；未填写时保留启用前的上传上限。
- **智能限速上行带宽**：填写可稳定使用的上行带宽，单位 Mbps。
- **预留带宽、播放带宽系数**：给其它流量和播放突发留出余量。

开播、恢复或拖动后的15秒及码率缺失时优先让出上传。暂停或停止后等待所设时间，再逐步恢复；未配置下载限速时保留下载设置。停用时恢复插件修改前的设置，不覆盖期间手动修改的上传值。

播放需求按媒体服务器码率估算，不是对客户端缓存或实际网络吞吐的测量。经代理访问时，应核实不限速地址范围，避免远程播放被识别成内网播放。
