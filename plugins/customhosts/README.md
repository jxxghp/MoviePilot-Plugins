# 自定义 Hosts

启用插件后保存配置，将自定义映射写入运行 MoviePilot 的系统 Hosts 文件；Docker 部署时修改的是容器内的 `/etc/hosts`。

每行填写一个 IP 和一个或多个域名，支持 IPv4、IPv6，以及以 `#` 开头的注释。多个域名可以分行使用同一个 IP，例如：

```text
# 以下地址仅用于演示格式
203.0.113.1 first.example
203.0.113.1 second.example alias.example
2001:db8::1 ipv6.example
```

再次保存有效配置会替换此前的插件区块；关闭插件会移除该区块。系统原有记录保留，已存在的同名域名不会被插件覆盖；如需更换其 IP，请先在原配置来源处理重名记录，再保存插件配置。
